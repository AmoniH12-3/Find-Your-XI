# Find Your XI — Project Plan

## Project Vision

Find Your XI is an open-source sports analytics platform designed to help fans discover Premier League teams and players that match their interests, playing preferences, and sports personality.

The project will initially focus on the Premier League, with the long-term goal of expanding the platform to other sports, including the NBA.

---

## Problem

New fans, particularly fans outside of traditional football markets, may find it difficult to decide which Premier League team or players they should follow.

Find Your XI aims to make that discovery easier by translating football data into simple, understandable recommendations.

---

## Core Questions

### Team Discovery

- Which Premier League teams score the most?
- Which teams have the strongest defensive records?
- Which teams create the most chances?
- Which teams dominate possession?
- Which teams play the most aggressively?
- Which teams rely heavily on young players?
- Which teams have the most balanced statistical profiles?

### Player Discovery

- Who are the best players at each position?
- Which players are the strongest attackers?
- Which players are the best creators?
- Which players are the strongest defenders?
- Which players have similar statistical profiles?

### Player Comparison

- How does one player compare with another?
- How does a player compare with others at their position?
- What are each player's statistical strengths and weaknesses?

---

## Future Feature: Find Your Club

Users will answer questions about the type of football they enjoy.

Examples:

- High-scoring football
- Strong defense
- Possession
- Creativity
- High pressing
- Fast attacking football
- Young players
- Superstar players
- Balanced teams
- Underdog mentality

The system will use team performance data to recommend clubs that best match the user's preferences.

---

## Future Feature: Find Your Player

Users will be able to discover players based on playing style and statistical characteristics.

---

## Future Feature: Settle the Debate

Users will be able to compare two players using position-adjusted statistics and other analytical measures.

## Development Phases

### Phase 1 — SQL Foundation

- Identify appropriate football data sources
- Understand the available data
- Design the database schema
- Load initial data
- Practice SQL queries
- Analyze team and player performance

### Phase 2 — Analytics MVP

- Create team performance profiles
- Create player profiles
- Calculate per-90 statistics
- Create player comparisons
- Create position-based rankings

### Phase 3 — Recommendation Engine

- Define team characteristics
- Define user preferences
- Develop team matching methodology
- Create the first Find Your Club model

### Phase 4 — Data Engineering

- Automate data ingestion
- Build transformation pipelines
- Implement data quality checks
- Introduce Python
- Introduce dbt
- Implement orchestration
- Containerize the application

### Phase 5 — Public Platform

- Build interactive web application
- Deploy the platform
- Publish documentation
- Create public analytics
- Develop social media content

### Phase 6 — Expansion

- Expand to additional Premier League seasons
- Improve player comparison methodology
- Add additional football competitions
- Develop an NBA version
- Explore a reusable multi-sport architecture

4. Open-source development
